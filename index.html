常见问题

了解我们如何守护你的数据主权与思考资产

Synapse Note 复利笔记 是什么？它与普通笔记软件有什么区别？

Synapse Note 是一款专为终身学习者、研究员与深度思考者设计的本地优先双链知识库与 AI 认知镜像。它通过 Markdown 双向链接与知识图谱串联笔记，结合自带 API Key 的白盒 AI 深度问答、思维模型红队沙盘和十维研报矩阵，帮助你将零散记录沉淀为可复利的认知资产。

我的数据保存在哪里？如何保障隐私安全？

你的所有笔记、附件、实体和向量索引全部 100% 存储在设备本地（SQLite 与沙盒文件）。应用没有注册登录系统，不包含任何跟踪、统计或广告 SDK。AI 功能直连你选择的大模型提供商，API 密钥加密保存在系统安全区（iOS Keychain / Android Keystore），发送前完全透明。

什么是 BYOK？AI 功能如何计费？

BYOK 即「自带 API Key」（Bring Your Own Key）。你可以自由填写 OpenAI、Anthropic Claude、DeepSeek、Google Gemini 等服务商的 API 密钥。所有 AI 计费直接在你的模型服务商后台按实际调用 Token 结算（通常每次深度问答仅需分厘），Synapse Note 不收取任何 AI 订阅溢价或中转费用。

没有网络或断网时能正常记笔记吗？

完全可以。除联网调用你配置的 AI 大模型外，应用的所有核心功能——包括 Markdown 编辑、双链跳转、实体图谱浏览、本地全文检索、公式渲染、PDF/Word 导出等——全部在本地离线运行。

如何备份与跨设备同步我的笔记数据？

你的笔记完全属于你。你可以一键将全部笔记导出为标准 Markdown 文件（包含 YAML 元数据），也可以导出为 SQLite 完整快照、高清 PDF 或 Word 文档。支持通过 iOS 系统的私有 iCloud 容器进行无缝多端同步，我们没有任何途径访问该私有容器。

Synapse Note Pro 包含什么？如何收费与取消？

Synapse Note 基础功能永久免费（含 30 篇笔记基础额度，额度用尽后次月起每个月赠送 5 次记录）。Pro 高级功能采用月度自动续期订阅制（仅需 ¥19.9/月，按月订阅随心取消），解锁突破 30 篇限制的无限笔记与星网图谱、无限次 AI 专属 Agent 深度剖析、包含全部 6 套精选专业知识母体、数据私有备份同步及学术级无损导出。所有购买均由对应应用商店（Apple App Store / Google Play / 华为应用市场）官方处理，你可以随时在系统应用商店的「订阅管理」中自主取消续订。
