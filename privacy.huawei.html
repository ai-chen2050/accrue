隐私政策

生效日期：2026-09-28 · 适用于 Synapse Note 复利笔记 iOS、Android 与 macOS 版

本页是华为应用市场渠道版：该版本没有任何联网分析功能，没有任何数据会离开你的设备。

Synapse Note（复利笔记）是一款纯本地运行的深度思考、双链知识管理与 AI 认知镜像应用。我们坚持本地优先（Local-First）与数据主权原则：我们没有用户账号系统，不架设任何中转或采集服务器。下面按「收集什么、存在哪、是否离开设备、你怎么删」四件事向你清晰说明。

1. 我们收集什么

我们不收集任何个人信息。应用没有任何注册、登录或身份认证环节，不采集设备唯一标识符（IDFA/IMEI）、地理位置或通讯录，不包含任何第三方数据统计、分析或广告 SDK，不上报应用使用行为，也没有任何远程崩溃日志上报。你在应用内撰写的笔记、双向链接、实体知识图谱、思维沙盘、数学公式、录音速记与照片附件，全部只存在你的设备本地，我们完全无法看到。

2. 数据存储位置

所有笔记记录、双链拓扑关系与本地向量索引均存放在应用私有沙盒目录内的本地数据库（SQLite）与文件系统里。 你自己配置的 AI 服务 API Key 严格存放在操作系统的硬件级安全存储中（iOS Keychain / Android Keystore），任何第三方应用均无法窃取。 应用支持本地一键全量快照与 Markdown 纯文本导出。若在 iOS 上开启「iCloud 私有备份与同步」，备份文件会存放于你个人的 Apple iCloud 私有文稿容器中，在你的相同 Apple ID 设备间无感加密同步；我们不具备访问或解密该容器的任何技术能力。

3. 第三方服务

本应用不接入任何第三方广告平台、行为分析平台或第三方账号登录 SDK。Pro 版高级功能的购买与结算完全由 Apple App Store、Google Play 或华为应用市场官方支付渠道处理，交易记录由对应应用市场根据其自身隐私政策管理，我们仅接收「是否已激活权益」的验证收据，不获取你的银行卡号、账单地址或支付密码。

4. 权限用途

权限用途是否必需
相册 / 图片库在笔记中插入图片、图表或扫描笔记卡片，图片仅保存在本地沙盒目录，绝不上传可选
相机拍照记录纸质书摘、白板手稿或随手笔记，照片仅保存在设备私有目录可选
麦克风用于语音速记灵感与语音转文字（依赖系统自带本地听写或你的专用配置），音频仅存本地可选

5. 数据删除与导出

你的数据完全归你所有，你可以随时自由处置：

  • 全量导出：支持随时一键将所有笔记导出为通用 Markdown 文件、高清矢量 PDF 或 DOCX 文档，无任何格式锁定；
  • 数据清空：在应用「设置 → 数据管理」中可一键彻底抹除本地数据库、向量缓存与 API Key 凭证；
  • 卸载即删：卸载应用会立即清除应用私有目录中的全部本地记录。存储在你个人 iCloud 中的备份文件可由你在系统设置中自行删除。由于我们不在任何云端留存数据，因此无需向我们申请注销或删除。

6. 儿童隐私

本应用面向学生、研究者、专业人士及终身学习者设计，不向未满 14 周岁的未成年人收集任何个人识别信息。所有学习笔记均保留在本地设备上，家长或监护人可完全掌控设备数据。

7. 政策变更

如因功能升级或法律法规要求需要修订本隐私政策，我们将在本页面发布更新版本并修改生效日期。重大变更亦将在应用内版本说明中显著提示。
