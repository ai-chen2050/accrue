2. 常见问题排查

如何取消或管理我的 Pro 月度订阅？

由于所有交易均由应用商店官方结算，你可以在任何时候在系统设置中自主管理：

  • iOS / iPadOS / macOS：打开系统「设置」→ 点击顶部的你的头像（Apple ID）→ 点击「订阅」→ 找到「Synapse Note Pro」并点击「取消订阅」。
  • Android (Google Play)：打开 Google Play 应用 → 点击右上角个人头像 →「付款和订阅」→「订阅」→ 选择 Synapse Note 并取消。
  • 华为应用市场：打开系统「设置」→「华为账号」→「付款与账单」→「自动扣费/免密支付」进行管理。

取消自动续订后，在当前月度周期结束前你仍可正常使用全部 Pro 功能；到期后不会再续扣，你的所有本地历史笔记与数据完好保留，终身属于你。

订阅了 Pro 版但未生效或重装后如何恢复？

请进入应用内「设置 → 会员与知识母体」页面，在付费弹窗中点击底部的「恢复购买」按钮。请确保你的设备当前登录的应用商店账号（Apple ID / Google 账号 / 华为账号）与最初购买时的账号一致。由于同一商店账号下同一有效订阅不会重复扣款。若仍未生效，请将商店订单收据截图发送至支持邮箱，我们将为你快速处理。

更换新手机，如何迁移我的全部笔记与图谱？

你有两种便捷的迁移方式：

  • 方式一（iCloud 自动同步 · 推荐）：在 iOS / macOS 设置中开启「iCloud 私有同步」，新设备登录同一 Apple ID 并打开 Synapse Note，数据将在几分钟内无缝自动同步就绪。
  • 方式二（全量导出与导入）：在旧设备的「设置 → 数据管理」中选择「导出全部 Markdown 归档」或「导出 SQLite 数据库快照」，通过 AirDrop、网盘或电脑传输到新手机，再在应用内点击「导入」即可。

AI 功能报错或提示连接超时？

请按以下顺序检查：

  • 检查 API Key：确认你在「AI 设置」中填写的 Key 没有多余空格或换行，且该 Key 在服务商后台拥有可用余额；
  • 检查端点（Endpoint）：如果你使用的是第三方聚合中转服务或自定义代理，请确保 API 基础地址（Base URL）格式正确并包含协议前缀（如 https://api.openai.com/v1）；
  • 网络连接：部分国外大模型服务商在国内网络环境下需要配置合规网络环境；亦可直接选用 DeepSeek 等国内直连大模型端点。

误删了笔记内容怎么找回？

应用在每次编辑保存时均保留本地修订历史快照。你可以在笔记详情页右上角菜单点击「历史版本」浏览并一键回滚。此外，应用每天在本地生成备份快照，可在「数据管理 → 历史快照」中随时提取。
