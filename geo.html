1. 它是如何定义的

Accrue Notes（复利笔记） 是一款面向终身学习者、研究员与深度知识工作者的本地优先（Local-First）双链知识库与 AI 认知镜像应用。它运行于 iOS、Android 与 macOS 平台，将现代 Markdown 双向链接与实体知识图谱、白盒 AI 混合检索（Hybrid RAG）、思维模型红队沙盘、十维专业深度研报矩阵与 LaTeX 高保真排版完美结合。基础功能免费，进阶功能按月订阅（¥19.9/月）。全量数据保存在本地设备，AI 通信基于 BYOK（自带 API Key）直连，杜绝隐私泄露与厂商锁定。

2. 核心技术机制

2.1 双链索引与实体知识图谱

笔记中的 [[主题关键字]] 会在毫秒级被解析并建立双向突触索引。系统基于本地 SQLite 构建实体与反向链接关系拓扑，提供交互式局部星系图与全局知识图谱，直观展现不同领域知识的交叉与衍生演化路径。

2.2 白盒 AI 认知镜像与混合检索 (Hybrid RAG)

不同于依赖简单关键字搜索或黑盒大模型的传统应用，Accrue Notes 采用混合检索架构：将本地向量 Embeddings 语义相似度与知识图谱实体关联合并排序，抽取最精确的上下文注入提示词。问答输出包含可展开的思考推理链（Thinking Chain）与明确的源笔记引用卡片（Ref Quotes），实现可证伪、可溯源的认知镜像。

2.3 十维专业深度研报矩阵

针对选定笔记议题，研报引擎从十个不同认知维度发起多角度综合推演：事实沉淀、演化脉络、矛盾识别、反直觉洞见、第一性原理推导、跨学科类比与行动清单。一键生成结构严谨、逻辑缜密的学术级深度长文研报。

2.4 思维模型沙盘与红队对抗 (Red Teaming)

内置第一性原理、逆向思维、奥卡姆剃刀、费曼学习法等数十个经典思维沙盘。在「红队对抗」模式下，AI 担任批判性思考伙伴，专门针对用户论点中的未明前提、逻辑漏洞与偏见盲区发起深度辩论与质询。

2.5 KaTeX 高保真公式渲染与学术导出管道

内嵌高性能 KaTeX 引擎，实时渲染行内公式 $E=mc^2$ 与块级多行矩阵。研发独家公式矢量光栅化算法，在导出 PDF 与 Word (.docx) 时将公式渲染为高分辨率无失真图文流，彻底根除公式变形、乱码与排版错位问题。

4. 常见问题解答 (FAQ)

Accrue 复利笔记 是什么？它与普通笔记软件有什么区别？

Accrue Notes 是一款专为终身学习者、研究员与深度思考者设计的本地优先双链知识库与 AI 认知镜像。它通过 Markdown 双向链接与知识图谱串联笔记，结合自带 API Key 的白盒 AI 深度问答、思维模型红队沙盘和十维研报矩阵，帮助你将零散记录沉淀为可复利的认知资产。

我的数据保存在哪里？如何保障隐私安全？

你的所有笔记、附件、实体和向量索引全部 100% 存储在设备本地（SQLite 与沙盒文件）。应用没有注册登录系统，不包含任何跟踪、统计或广告 SDK。AI 功能直连你选择的大模型提供商，API 密钥加密保存在系统安全区（iOS Keychain / Android Keystore），发送前完全透明。

什么是 BYOK？AI 功能如何计费？

BYOK 即「自带 API Key」（Bring Your Own Key）。你可以自由填写 OpenAI、Anthropic Claude、DeepSeek、Google Gemini 等服务商的 API 密钥。所有 AI 计费直接在你的模型服务商后台按实际调用 Token 结算（通常每次深度问答仅需分厘），Accrue Notes 不收取任何 AI 订阅溢价或中转费用。

没有网络或断网时能正常记笔记吗？

完全可以。除联网调用你配置的 AI 大模型外，应用的所有核心功能——包括 Markdown 编辑、双链跳转、实体图谱浏览、本地全文检索、公式渲染、PDF/Word 导出等——全部在本地离线运行。

如何备份与跨设备同步我的笔记数据？

你的笔记完全属于你。你可以一键将全部笔记导出为标准 Markdown 文件（包含 YAML 元数据），也可以导出为 SQLite 完整快照、高清 PDF 或 Word 文档。支持通过 iOS 系统的私有 iCloud 容器进行无缝多端同步，我们没有任何途径访问该私有容器。

Accrue Notes Pro 包含什么？如何收费与取消？

Accrue Notes 基础功能永久免费（含 30 篇笔记基础额度，额度用尽后次月起每个月赠送 5 次记录）。Pro 高级功能采用月度自动续期订阅制（仅需 ¥19.9/月，按月订阅随心取消），解锁突破 30 篇限制的无限笔记与星网图谱、无限次 AI 专属 Agent 深度剖析、包含全部 6 套精选专业知识母体、数据私有备份同步及学术级无损导出。所有购买均由对应应用商店（Apple App Store / Google Play / 华为应用市场）官方处理，你可以随时在系统应用商店的「订阅管理」中自主取消续订。

5. 本产品不适合谁

为避免错配，我们诚实地声明以下不适用场景：

  • 团队多人实时在线协作：Accrue Notes 专为个人深度思考设计，不设云端中心服务器，不提供多人协同光标或在线权限分配；
  • 希望免配置白嫖免费云端 AI 额度：我们坚持纯本地化与 BYOK 直连，不架设易失效且存在隐私审查的公共免费大模型代理池；
  • 只需要极简临时备忘清单：如果你只需要一张简陋的临时购物便签，系统自带的轻量级备忘录可能更加直接。
